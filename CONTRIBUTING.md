# Contributing

Thanks for helping improve the Pocket Python RPC Starter Kit.

1. Fork the repository and create a focused branch.
2. Keep the project dependency-free unless a dependency is clearly justified.
3. Add or update automated tests for code changes.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Never commit API keys, private keys, payment credentials, access tokens, or personal data.
6. Include the Python version, operating system, exact commands, expected result, and actual result when reporting a bug.

Keep examples beginner-friendly and distinguish mocked test output from live endpoint results.
